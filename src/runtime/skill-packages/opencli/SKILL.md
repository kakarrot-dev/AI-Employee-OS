# OpenCLI 社交平台研究

## 适用边界

仅执行 Runtime 暴露的只读搜索。不得登录新账号、修改浏览器状态、发帖、评论、点赞、关注、发送消息或调用未列出的 OpenCLI 命令。

## 输入契约

- 查询应同时包含主题和用户真实可能使用的表达，可按平台语言差异调整关键词。
- 不提交个人隐私、凭据、内部资料或要求识别匿名用户的查询。

## 工作方法

1. 将三个平台视为不同样本，不因某个平台结果更多就默认其更具代表性。
2. 保留原始 URL、平台、发布时间、作者信息（若公开提供）和摘要；不把互动量自动解释为真实性。
3. 合并重复转载，区分首发观点、引用和二次传播。
4. 对营销内容、机器人行为、无上下文截断和无法验证身份的观点降低置信度。
5. 分平台记录成功、无结果、未登录或适配器失败，避免把“调用失败”写成“平台上没有讨论”。

## 输出契约

按平台给出样本覆盖，再综合归纳共同主题、平台差异、代表性原帖、反例和限制。引用用户观点时使用概括，除非任务明确需要短引文。

## 完成标准

至少保留每项关键观点的可追溯链接；若只有单平台成功，结论必须限定为该平台样本；若全部失败，只交付故障与所需恢复条件。
