# Web 前端与客户端还原契约

## 基线与方案

基于本地 `main` 的 `7bc4621`（2026-09-08 创建分支时的 HEAD），分支为 `codex/web-frontend`。

Web 和 Electron 通过 `src/renderer/src/mount-client.tsx` 挂载同一个 `App`，保留同一套页面、头像、图标、布局、排版及亮暗主题。2026-09-09 在本分支的共享 Renderer 中增加可选 `ConversationScenes` 内容接入点，Web 提供会议场景；Electron 不传场景，保持原有消息页行为。没有复制整页，也没有修改 preload、Runtime 或共享业务契约。

Web 与 Electron 的差异只在宿主：Electron 由 preload 安装 `window.aiEmployeeOS`；Web 由 `src/web/preview-bridge.ts` 安装相同类型的演示适配器。Web 顶部另有 28px 演示说明条，不属于客户端画布。保留原生窗口按钮的安全区，但浏览器不提供 macOS 原生红黄绿窗口按钮。

## 运行

```bash
npm ci
npm run web:dev
```

访问 `http://127.0.0.1:5174/`。只绑定本机回环地址。

```bash
npm run web:test
npm run web:build
npm run web:preview
```

生产产物位于 `dist/web`，预览地址为 `http://127.0.0.1:4174/`。产物可由静态 HTTP 服务器提供，使用相对资产路径；不需要运行 Electron、Python Worker 或 Keychain Helper。沿用项目现有 Node/npm 版本和依赖，没有新增依赖。

## 数据与行为

- `catalog.json` 来自当前源码的 `EmployeeService`、`ResourceService`、`ExpertGroupService` 初始化定义。使用全新的内存数据库导出，不读取本机用户数据库、账号、Token 或历史任务。
- `npm run web:catalog` 可以重新导出目录。导出器只执行 seed/list/detail，不执行 probe、模型调用或 Worker。生成结果应随源码变化一同复核。
- 对话、示例事项、记忆为显式演示数据；内置目录的可用/已发布等状态表示初始化样例，不代表浏览器取得执行权限。模型凭证始终缺失、模型未验证、飞书未连接。
- 会话新建、输入、固定演示回复、取消、归档；专家草稿创建/编辑、禁用/恢复/归档、受约束删除；总管设置和记忆编辑在当前页面内生效，刷新恢复。档案字段继续使用原契约校验。
- 桌面页面原有的个人资料、主题等偏好继续使用当前浏览器 origin 的 localStorage；它们可能跨刷新保留，不与桌面存储共享。
- 模型测试/发布/回滚、真实任务执行/审批、宿主文件访问、飞书 OAuth、资源探测与记忆模型操作明确拒绝。会议场景仅生成浏览器内的摘要 Blob 并按用户点击下载，进度和验收均明确标记为演示。
- 浏览器服务只提供前端，不包含 HTTP 后端。以后接入真实 Web 服务时，需以相同 Bridge 契约实现鉴权、传输和事件订阅；不可把桌面 IPC 直接开放到公网。

## 会议专家团场景（Web 0.1）

入口为 **通讯录 → 专家团 → 会议专家团 → 进入会话**。表单填写主题、北京时间和参会人，点击“发起会议并生成摘要”后约 28 秒完成压缩演示，不等待真实预约时间。

消息页继续使用客户端的 Toolbar、Rail、会话列表、消息画布、Composer、MatterSidebar 和 MatterDetailModal。场景仅注入表单、进度、事项内容和摘要交付：

- 表单复用 `ChatMessage` 与 `MessageActionCard`，明确选择场景，不做意图识别或追问。
- 预约、邀请、会议通知、录制就绪、妙记转写重试、专家团协作和交付使用同一消息流。所有回复署名“会议专家团”，三位成员的分工在加入记录、事项详情与交付核对记录中呈现。
- 右侧始终是客户端事项列表，每场会议只有一个事项；八步流程在事项详情中展示。
- 只输出摘要文档附件，不在消息或事项详情中展示妙记原文、摘要正文。统一附件菜单支持浏览器预览与下载，摘要包含示例来源、结论、负责人和截止时间。
- 表单提交后事实冻结；普通消息只记入会话，不修改会议或创建新事项。各会话表单与输入草稿独立，流程计时器由 Web 宿主持有，切换会话或模块不会中断。归档会话停止该会话流程和待发送的本地示例回复；刷新恢复初始样例。
- 预约 ID、实际会议 ID 与妙记来源分别关联；会议结束不能直接生成摘要，需要经过录制就绪、转写读取与三位成员核对。领域测试覆盖非法跳转、重复回调、错配来源和摘要归属。

实现集中于 `src/web/meeting/`。没有飞书凭证、事件订阅服务或模型调用；状态通知、转写内容、邀请回执与三位专家工作均是本地示例。未来真实接入需在服务端实现回调验签、幂等状态迁移、妙记权限与转写重试，不能将本地定时器当作真实 API 完成依据。

## 验收证据

- 共享消息页在原有结构上增加可选场景插槽；未传入场景时仍走客户端原有分支。默认页面回归测试与排版、尺寸、组件契约共同验证这一边界。共享业务契约与 Runtime 未改动。
- Web 类型检查、现有排版与布局契约检查、Vite 生产构建通过。
- 新增 Web 测试覆盖目录隔离、草稿字段验证与治理、会话回复/取消/退订、拒绝真实副作用、五个模块及八个系统设置页。结合既有 Renderer、Shared 和组件契约测试执行 `npm run web:test`，19 个测试文件、147 项测试全部通过（含本轮领域与场景集成测试）。
- 浏览器已检查消息、专家资料/设置/创建、Skill/Tool 详情、连接目录与全部系统设置页；开发页与生产产物预览均正常加载，未出现控制台错误。
- 画布 960×640、1280×820、1600×1000：顶栏均为 40px、Rail 均为 56px、无页面级横向溢出。浏览器视口额外包含 28px 演示说明条；小于客户端最小尺寸时允许滚动，不擅自改成移动端布局。
- 保留 main 原始头像和完整页面资源，构建会提示主页面 JS chunk 大于 500kB；这不影响构建通过，尚未另做资源压缩或页面拆包。
- 本轮浏览器完成会议表单、同名参会人选择、普通备注、离开页面继续执行、事项八步详情、摘要预览和实际下载验证。下载文件为 `客户端融合浏览器验收-会议摘要.md`，含专家团、妙记示例来源、结论和行动项，无会议原文。
- 本轮没有接入真实后端，也未将同一真实数据库状态下的 Electron 与浏览器截图做逐像素差分；不能把源码复用与页面检查表述为真实执行已完成。
