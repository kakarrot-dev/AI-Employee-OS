# Open Claude UI 客户端重构契约

日期：2026-10-16。范围由用户“使用 Caho1/open-claude-ui 的桌面端重新重构当前客户端”授权。

## 目标与事实

当前正式客户端是 Electron + React。上游固定为 `Caho1/open-claude-ui@f504349419118a32804ce3a7fae74593070bf945`，采用 MIT 许可；它提供组件、主题、交互 Hook、Electron 窗口示例及设计文档，未提供本产品需要的完整业务应用。迁移采用其源码和设计机制，接入现有窄 Bridge。

Design Read：面向通过总管组织 Agent 工作的个人用户，以稳定的单侧导航、暖灰表面与陶土强调色，优先支持对话、任务确认和结果使用。变化度 3：同一桌面壳覆盖六模块；动效 2：仅状态与空间过渡，支持减少动态效果；密度 6：目录紧凑、正文舒展、高级信息按需展开。

## 实现边界

- 正式客户端使用独立的生产样式入口，不再加载 Web 原型 CSS。旧 Web 原型保留其演示与现有未提交工作，不作为新桌面界面的视觉验收依据。
- `DesktopShell` 负责窗口安全区、一级导航、上下文目录与工作区域。详情、表单、弹窗、按钮、分段选择、消息和附件组件全部迁移到 CDS 外观；保留业务类型、状态和回调。
- 原样保留上游主题文件；生产 Token 只映射 CDS 颜色、圆角和字阶。按钮采用上游 `CdsButton`，图标统一 Lucide，采用 Tailwind 编译其原子类。所有旧桌面/原型 CSS 均移出生产导入链，业务样式从 CDS 重新实现；不为动效引入新运行库。
- 桌面输入框是受控展示组件。附件导入、发送、取消、模型配置、审批和任务状态仍由现有 Bridge 与 Runtime 负责。中文输入法合成不触发发送，Shift+Enter 换行。
- 采用上游 40px 底部容差与 150ms 手动输入保护的滚动机制；阅读历史时不因输出追加而跳走，并提供返回最新位置的操作。
- 模型选择显示真实已保存配置及 Provider 状态；不产生会话级模型切换、推理强度、录音、离线队列或虚构工具状态。
- 按上游设置 1200×800 默认、600×400 最小窗口与 45px 顶栏，保留原生窗口控件、安全沙箱、数据库与权限。已有 Runtime/SDK/封装和签名 helper 不因本次界面重构而改写或重签。

## 消息与 Markdown 的完整适配

- `ChatMessageBubbles.tsx:68-101`：用户时间戳11px mono、内部间隔6px、14.5px/1.625正文、10×16px内边距、18px气泡、85%/640px起75%宽度和微阴影。用户附件位于气泡外上方，正式桌面不显示重复用户头像/姓名。
- `ChatMessageBubbles.tsx:134-148,196`：AI回复最大672px、内部间隔14px，20px头像/12px名称/10px真实模型标识/11px时间处于同一头部；正文15px/1.625、无闭合框。普通用户消息与AI回复完整展示，不再套旧六行截断；过程摘要仍保留原业务折叠。
- `CodeBlock.tsx`：12px外壳、36px语言工具栏、14px内容内边距、13px/1.625等宽字体、黑色背景和边线；复制成功反馈2.5秒，失败可重试，代码空白保持原样。上游示例不含语法着色引擎，本次不宣称已引入 Tree-sitter 或语义高亮。
- 桌面原本拒绝所有网页权限，直接使用上游 `navigator.clipboard` 会失败。新增仅文本写入的 `desktop:copy-text`，校验可信Renderer和当前主窗口、限制100万字符，调用Electron剪贴板；不开放读取或放宽网页权限，Runtime/Provider不参与。浏览器原型继续使用浏览器剪贴板。
- `AttachmentCard.tsx`：128×96px磁贴、10px内边距与圆角、32px类型图标；输入区chip采用4×10px内边距、16px徽章和120px文件名截断。类型颜色和悬停阴影按源码；不模拟上传或执行状态。
- `McpToolDecisionCard.tsx`：16px圆角、10×14px头/尾内边距、状态边线；保留现有审批回调与两决议语义，不引入上游示例的模拟执行和“始终允许”。长异常状态可换行，避免裁掉待核实警示。
- `StatusIndicators.tsx:164-166`：独立3px×1.15em流式光标，aria-hidden，只随真实活跃输出显示。当前Runtime未提供可展示的思考文本，不虚构思考内容或耗时。

上游**没有**完整Markdown renderer/prose CSS，也没有逐项定义h1–h6、列表、引用、表格、任务列表、链接和分割线的数值。以下为明确的CDS适配：h1到h6分别20/28、18/24、16/22、15/20、14/20、13/17px；段落14px间隔、标题上24/下12px、列表24px缩进与4px项距；引用用2px单向引导线；行内代码12/17.5px；表格14/20px、8×12px单元格、发丝行分隔及独立横向滚动。其余共用上游balance/pretty/anywhere排版、字体栈和主题。GFM解析语义、表格左右中对齐、只读任务勾选、原始HTML/危险链接隔离均保留。

Markdown节点、完整长文、消息插槽、复制生命周期和键盘菜单均有确定性测试。离线GUI样例在 `docs/audits/evidence/2026-10-16-open-claude-ui/markdown-fixtures.json`，明确标注未调用模型，只写入隔离测试profile。

## 页面与验收

| 页面 | 保留的真实路径 | 界面验收 |
| --- | --- | --- |
| 消息 | 会话读取/创建、附件、发送/取消、流式回复、审批、交付 | 导航折叠、草稿与焦点、中文输入、长文阅读、输入框常驻 |
| 事项 | 全局任务读取、状态筛选、详情和受限重试 | 长标题、真实状态、错误重读、右侧栏按需展开 |
| 通讯录 | 员工/专家团目录、创建/编辑/测试/发布 | 原表单和 Modal 可达，能力绑定保留 |
| 能力 | Runtime Skills/Tools、依赖、健康与员工关联 | 搜索、空态和错误区分，保持只读 |
| 连接 | 飞书/Teams 真实连接状态与确认 | 已连接目录准确，未连接入口与说明可读 |
| 系统 | 八个设置分区、模型、权限、记忆与用量 | 单栏阅读、长内容滚动、浅/深/跟随系统主题 |

确定性门禁：相关 Renderer 回归、滚动与输入交互测试、TypeScript、生产构建、既有布局/原型门禁。运行门禁：隔离 userData 的真实 Electron 启动，六模块导航与关键弹窗操作；600×400、960×640、1200×800、1600×1000 的布局检查与截图审查。Provider 的真实调用、外部写入与发布级签名分别记录，不能从 UI 回归推定通过。
