# Electron 客户端界面检查与优化方案

日期：2026-10-19。状态：设计建议，尚未实施。范围：正式 Electron 客户端，保留现有功能。

## 检查依据与边界

通过 `npx electron .` 启动当前工作区构建，实际访问 `out/renderer/index.html`，逐项操作导航、展开事项边栏、打开并关闭员工设置。截图为本轮采集的原始 2400×1600 像素窗口画面，保存后逐张打开核验。窗口代码默认尺寸为 1200×800；截图像素不等于 CSS 像素。左上角紫色系统覆盖标记不作为应用设计问题。

检查目标：用户能找到会话和员工、分清事项状态、识别交付结果，并理解配置操作是否已保存。本轮属于实机界面审查与设计方案，不修改 Renderer、不执行真实模型请求、不修改员工配置、不授权外部服务、不验证任务执行或文件内容。启动可能触发应用自身的状态读取与健康检查。

参考实现：`src/renderer/src/components/DesktopShell.tsx`、`design-system/tokens.css`、`design-system/primitives.css`、`design-system/desktop.css`、`TaskModule.tsx`、`TeamModule.tsx`、`ConnectionsCatalog.tsx`。沿用现有 Open Claude UI 主题、组件与资产，不另起 Web 原型。

## 逐步检查与截图

### 1. 已有对话与交付结果：可用，结果层级待优化

![已有对话](01-conversation.png)

优点：输入区常驻，参与员工身份明确，交付文件与验收记录有独立入口。

观察：阶段完成、文件已生成、已交付、交付结果已完成等信息重复；小文件卡片截断名称，而文件右侧保留较大空白；验收入口与文件相距较远。一级导航和新建入口占侧栏上半部较多空间。

建议：保留全部时间线与验收信息，用较轻的阶段摘要呈现过程，强化最终交付区；文件使用横向条目展示名称、类型、打开方式，验收入口放在同一区域；不移除消息或执行证据。

### 2. 展开事项边栏：展开正常，空间分配待优化

![事项边栏](02-inspector.png)

优点：无需离开对话即可定位关联事项。

观察：单个事项仍占固定宽度侧栏，挤压消息和输入框；开关仅为箭头，视觉上较难理解用途，但已有可访问名称。

建议：保留开关和事项定位能力；为开关补可见事项图标或数量提示。在窄窗口中使用按需覆盖面板，保留关闭后的阅读位置与草稿。覆盖形式是待实施设计建议，本轮未验证。

### 3. 事项目录：可用，状态语义优先修正

![事项目录](03-tasks.png)

优点：筛选含计数，列表同时显示员工、状态与日期。

观察：“等待参会人确认”与“执行失败”都显示红色状态点。源码确认 `needs_attention` 与 `failed` 同映射为 danger。左侧筛选文本居中，计数和箭头排列不齐；顶部“我的事项”与正文标题重复。

建议：完成用绿、失败用红、等待/需处理用琥珀、运行用强调色、取消用灰；颜色始终配文字。保留业务状态，区分等待他人与用户需要行动的文案。筛选改为文字左对齐、数量右对齐，不隐藏零计数筛选。列表使用稳定的标题/员工/状态/时间列，长标题允许受控换行。

### 4. 员工目录与详情：可用，身份与操作层级待优化

![员工详情](04-team.png)

优点：有头像与职责摘要、运行模型、配置版本和能力摘要，已有信息充足。

观察：详情把较长职责作为主标题，姓名较弱；设置与解雇并排显示为小图标，距离主要内容较远。列表空间不足，底部员工需要滚动。

建议：姓名作为主标题，职责为副标题，说明控制阅读宽度；状态保留一处主要呈现，模型和版本降为次级信息。设置提供清晰文字或图标加提示；解雇保留原确认机制，降为次要危险操作。压缩全局导航高度，为员工列表释放空间。

### 5. 员工设置：打开关闭正常，保存反馈缺失

![员工设置](05-employee-settings.png)

优点：基本资料、提示词、模型与能力、记忆分区明确，字段有长度与计数提示。

观察：内容集中上半部，名称与职责并列，长职责几乎占满；头像提示出现“2 / MB”断行。弹窗没有明显保存状态。源码存在 650ms 延迟保存逻辑与 saveState，但没有在界面呈现该状态。

建议：保留自动保存，不额外引入一套保存流程；顶部稳定展示“未保存 / 保存中 / 已保存”，失败时给出原因和重试。说明保存到草稿与生效版本的区别；不得把草稿保存显示为已发布。字段设合理宽度，说明区保持完整，“2 MB”作为不可拆分片段。未执行修改、保存、错误和关闭期间的保存竞态测试。

### 6. 能力目录：可用，重复信息与长内容待整理

![能力目录](06-capabilities.png)

优点：区分 Skills/Tools，含版本、健康状态、执行步骤、依赖与绑定员工。

观察：列表副标题“v2 · 可用”和右侧“可用”重复；详情已有摘要和步骤，后面继续展示完整 SKILL.md，页面较长。

建议：列表只保留一次状态，副标题展示版本或用途；详情优先摘要、依赖、绑定关系；完整原文提供明确展开入口，保持全部内容可访问。数据读取可能异步更新，树与截图的绑定数量曾短暂不同，本报告不据此判定数据错误。

### 7. 连接目录：可用，支持范围表达需改进

![连接目录](07-connections.png)

优点：飞书和 Teams 有官方图标、能力说明与连接操作，顶部说明当前支持范围。

观察：页面计入 12 个应用，当前仅飞书和 Teams 有连接按钮，其余均显示“未连接”。这些状态容易让人以为应用都已支持。左侧只有空列表时仍占完整栏宽；顶部灰色概况块占用较多首屏空间。

建议：保留全部应用展示，明确区分“可连接 / 已连接 / 连接异常 / 暂未开放”；暂未开放不得显示可操作假象。计数区分当前可用连接与展示目录；缩短概况区。空侧栏补充与当前连接相关的说明或入口，不新增连接能力。异常原因仍须在详情里核验，不能从截图推断授权过期或服务故障。

### 8. 系统个人资料：可用，对齐与表单宽度待优化

![系统设置](08-system.png)

优点：系统子栏目明确，保留头像和个人名称编辑。

观察：子导航图标在左，文字与箭头却整体居中；名称输入框拉伸过宽，页面大量留白不能帮助完成任务。

建议：系统子导航采用统一三列布局：固定图标、左对齐名称、靠右箭头。个人资料等短表单限制在合理阅读宽度，主内容与其他设置页统一起点。

## 推荐方向与空间契约（设计建议）

保留现有浅色画布、浅灰侧栏、陶土色强调、Lucide 图标与头像资产。目标是形成安静、清晰、适合长期工作的桌面工作台。没有用户研究证明“高级感”等偏好，本方案以降低寻找和辨认成本为启发式目标。

- 外壳：保留单侧栏与全部六模块；建议默认侧栏 264px，折叠保持 56px。常规一级导航行高建议 30–32px，压缩上方纵向间距；不缩小图标按钮现有可点击区域。短窗口优先让上下文列表可滚动。
- 标题栏：保留原生窗口按钮和拖拽安全区。主标题与页面身份固定位置，正文只在有新信息时重复标题。
- 内容：对话沿用现有 768px 阅读上限；表单建议 640–720px；业务列表按空间伸展。24px 页面边距、16px 组件间距、8px 元素间距作为本轮建议基线，不强行统一所有场景。
- 字体：沿用本机中文字体回退；正文 14px、说明 12–13px、页标题 20–22px。中文长标题检查断行，不以扩大所有字号解决层级问题。无需新增字体下载。
- 表面：主工作区接近白色、侧栏浅灰；分组优先留白和细分隔线，减少大面积深灰概况块。强调色用于主要操作、当前选中与焦点，避免状态颜色承担导航含义。
- 组件：导航、筛选、列表、状态标签、表单反馈、文件交付分别使用明确变体；避免把通用按钮的居中布局直接用于目录导航。
- 动效：沿用已有短过渡；不增加装饰动画。展开边栏与内容收起需保留焦点，并尊重减少动态偏好。

所有尺寸均为建议值，需实施后用实际窗口验证，不是已测性能或用户认可结果。

## 实施顺序与验收计划

| 编号 | 优先级 | 改动 | 应保留行为 | 实施后验收 |
| --- | --- | --- | --- | --- |
| UI-01 | 第一批 | 统一侧栏导航/筛选左对齐，压缩无效纵向间距 | 六模块、计数、搜索、折叠、会话与员工选择 | 1200×800、960×640、600×400 下入口可达，长列表能滚动；切页不丢草稿 |
| UI-02 | 第一批 | 区分等待、需处理与失败的状态视觉 | Runtime 状态、筛选、事项详情与确认 | 同一状态在目录、对话与详情含义一致；不只依赖颜色 |
| UI-03 | 第一批 | 统一标题、内容起点、短表单宽度 | 全部设置字段与操作 | 长中英文、长名称、空数据不溢出；正文与表单对齐 |
| UI-04 | 第二批 | 交付文件横向呈现、过程摘要与结果分层 | 全部消息、文件操作、来源与验收入口 | 长文件名可识别；打开方式与完整验收可达；消息位置稳定 |
| UI-05 | 第二批 | 员工设置保存状态反馈 | 当前自动保存与版本治理 | 修改、等待、失败、重试、关闭/重开结果与真实状态一致 |
| UI-06 | 第二批 | 员工详情身份层级与危险操作降级 | 设置、解雇及确认 | 设置易找，解雇仍需原确认；身份在目录与对话一致 |
| UI-07 | 第三批 | 能力信息去重、完整原文按需展开 | 完整 Skill/Tool 内容与绑定关系 | 不遗漏依赖、权限、版本和原文；键盘可展开与收起 |
| UI-08 | 第三批 | 区分连接支持范围、压缩概况区 | 全部目录条目、已有飞书/Teams 连接流程 | 暂未开放与真实未连接可区分；不误导支持范围 |
