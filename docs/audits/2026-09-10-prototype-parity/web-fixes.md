# Web 原型修复与复验

日期：2026-09-10。基于首次审计后的未提交工作区实施；原审计 README 和隔离失败证据保留为修复前快照。本文件只记录本次 Web 修复，不替代客户端全量验收。

## 已修复

- 五个主模块使用同一 AppShell、Toolbar、Rail、ContextPane 和 DetailPage。资料、选择目录、卡片、搜索、设置、Markdown、附件及消息确认动作调用共享组件；薄适配函数只转换字段和回调。
- 取消消息页条件挂载样式，Web 与客户端从入口全局加载相同样式。最终栏宽收回 layout.css，主题收回 styles.css，字体族、字号、字重、行高、字距只引用 typography.css。共享适配层不再重复定义尺寸和主题。
- 顶栏与列表栏标题回归 14px / 18px 语义刻度；Portal 中的弹窗操作图标也使用 16px 控件 Token。旧文档中的 1600×1000 外壳上限已按现有客户端最大化行为及测试纠正，外壳铺满窗口，消息和详情保留阅读宽度限制。
- 导航和目录选中项提供 aria-current；能力 Tabs 与通讯录 Tabs 使用 React Aria 的方向键切换。会话、能力、记忆搜索提供无结果反馈，连接目录明确暂无连接。
- 会话删除清理顶层会话与演示状态，删除最后一项后清空工作区，可重新创建。员工设置显式校验并保存名称、说明、提示词、模型、能力、头像和记忆选择；删除对准当前员工，最后一位删除后可重新开始。能力详情中的绑定人员随配置派生，点击进入对应员工。
- 上传文件保留在所属会话，发送后提供浏览器附件预览/下载，关闭释放 Blob URL。只有元数据的历史示例附件禁用打开，并明确说明没有文件；不再展示无效果的 Finder 或系统应用菜单。
- 方向确认使用共享动作卡片并保留演示结果；提出修改聚焦输入框。权限、预算及示例模型配置跨页面保留；记忆项打开详情。Web 无法执行的启动恢复、系统通知和本地诊断操作禁用并说明原因，示例模型验证不冒充真实连接。
- 共享附件轮播修复减少动态效果：普通模式平滑滚动，减少动态效果时立即滚动。Web 弹窗继续使用 React Aria 进入/退出生命周期、Escape 和焦点恢复。
- Web TypeScript 项目覆盖原型源文件，修复原先三个 TS6307。布局检查不再要求在 Web 重复实现组件；新增共享样式加载、组件重复实现、尺寸/主题重复定义防护。排版检查包含实际被 Web 引入的共享适配 CSS，并检查字体族。

## 边界

本次共享修复同时作用于客户端的公共视觉组件（语义字体、Portal 图标、列表选中语义、附件减少动态效果）。没有修改客户端会话草稿持有、流式投递或原生页签业务实现；原审计 F01/F02 及客户端专属键盘/事项定位/弹窗生命周期差异仍需单独修复。

Web 仍为本地演示，未新增或验证真实模型、飞书、Teams 授权和外部写入。示例状态切页面保留、刷新恢复初始数据。本轮未运行 Electron 完整生产打包或重新完成客户端视觉验收，因此不声明两端全量交互已经一致。保留既有未提交工作，未提交或推送。
