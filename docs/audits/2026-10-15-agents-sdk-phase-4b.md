# 第四阶段 4B：首轮运行与开销基线

日期：2026-10-15。进入条件已由 [总管格式纠正验收](2026-10-15-manager-review-format-repair.md) 满足。**本轮完成测量和开销定位；尚未实施执行期分派调用的消除，不作整体性能改善或安装体积下降结论。**

机器证据：[4B JSON](evidence/2026-10-15-agents-sdk-phase-4b.json)。所有测量使用独立数据和当前最终构建；没有改正式客户端或新增 Runtime 行为。

## 进程与体积

通过真实 Electron utilityProcess 分别启动 Runtime 和 Provider，各测量 3 次。从 fork 至 ready 计时；ready 后 8 次、间隔 250 ms 采集该 PID 的 `ps RSS`。没有触发模型请求，没有清空系统缓存；这是进程基线，不是整机冷启动或完整 GUI 启动。

| 指标 | Runtime | Provider |
|---|---:|---:|
| 启动中位数 | 118.1 ms | 75.9 ms |
| 启动观测范围 | 112.0–199.4 ms | 63.5–137.1 ms |
| 空闲采样最大 RSS | 107.7 MiB | 68.5 MiB |

RSS 包含共享驻留页，不等于独占堆或全客户端内存；两个进程分别测量，不能把采样峰值简单相加当作整机峰值。

当前 Runtime JS 为 2,695,984 字节（约 2.57 MiB）。整个 `out` 构建目录占用约 20.8 MiB。开发环境的 DeepAgents `.venv` 占用约 84.2 MiB，记忆服务 `.venv` 约 171.1 MiB，`@openai/agents-core` 安装目录约 12.7 MiB。目录值来自 `du -sk`，受硬链接、共享缓存和打包复制方式影响，不等于可从安装包移除的字节数。

DeepAgents 环境仍为历史 Run 保留，记忆服务也仍有独立 Python 依赖。SDK 执行路径解除 worker 依赖并不自动缩小安装包；正式安装包体积和人工界面验收仍在后续阶段。

## Poe 任务开销

代表性自然语言双员工任务成功交付：读取 DOCX → 交接 → 创建短文档 → 回读 → 总管格式纠正后交付。任务前的会话路由单独入账。

| 阶段 | Run 内实际请求数 | 输入 Token | 输出 Token |
|---|---:|---:|---:|
| 执行期总管分派 | 4 | 9,532 | 295 |
| 员工开始 | 2 | 6,064 | 133 |
| 工具提案 | 2 | 7,067 | 283 |
| 工具结果后继续 | 3 | 11,864 | 699 |
| 首次最终审核 | 1 | 5,286 | 1,407 |
| 总管格式纠正 | 1 | 7,108 | 1,126 |
| 合计 | 13 | 46,921 | 3,943 |

另有 1 次会话路由，故端到端共 14 次请求。该 Run 合计 50,864 Token，创建至交付 72.424 秒；只有 2 个原 Assignment、3 项实际工具动作和一次格式纠正。它是单个观测样本，不能外推成功率、平均时延或单次固定成本。货币金额及取消请求账单未验证。

格式修复同时消除了最终审核额外拼接的 SDK root history。对同一份历史成功请求作静态投影，保留完整 Runtime 证据消息时，序列化输入由 14,305 字节变为 10,950 字节，减少 23.5%。这是相同证据的字节量比较，不是实测 Token 或账单节省比例。

## 下一项减重候选

当前 `TeamExecutor.managerModel` 对每个执行期分派都调用 Poe，但当时 Runtime 已经冻结员工顺序、当前 Assignment、唯一工具名及唯一合法 assignmentId，模型没有合法选择空间。本样本该环节用了 4 次请求、9,827 Token，占 Run 请求数约 30.8%、Token 约 19.3%。

优先候选是：由 Runtime 根据冻结计划产生唯一合法的 SDK 分派，保留 SDK 子员工图和原工具提案/审批路径。实施时必须区分 Runtime 控制事件与真实模型回执，不能伪造 Provider usage；兼容旧付费分派回执、原生 SDK 检查点和崩溃重放，并回归审批、取消、未知写结果与业务返工。随后使用匹配任务进行 Poe 对照，验证实际请求及 Token 变化。本轮记录候选及其收益边界，尚未修改该执行契约。

本轮代码的主要成果是纠正格式错误的恢复归属并冻结证据。低内存、低成本和低包体仍需分别用数据证明。
