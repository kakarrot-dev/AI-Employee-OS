# 前台单智能体原型 v0.1

更新：2026-09-17。依据用户决定：“前台先不考虑事项场景专家团了，先以单智能体为主”。补充决定：前台服务高校学生与教职工，隐藏能力和连接菜单，专家市场沿用原招募页的卡片布局，展示适合学习、教学、科研、办公与生活的智能体；默认仍与助理聊天，也可主动找专家聊天。本文件是当前 Web 前台原型的范围与交互契约。

## 本期范围

- 左侧“专家市场”下方展示“知识库”，附“敬请期待”标签；入口禁用，鼠标及键盘均不能触发导航，折叠后保留知识库图标与可访问名称，不挂载知识库页面。

- 主流程：默认与助理聊天 → 输入文字或附件 → 查看助理回复；需要专家时，从专家市场或助理空会话的“找专家聊天”进入目录，选择专家后独立对话。
- 默认助理新对话使用轻量欢迎页：品牌图标与姓名问候、居中标题、720px 输入框集中展示；下方提供学习辅导、备课办公、旅行攻略、聊聊心事四个快捷提问和“找专家聊天”入口。点击提问仅填入输入框并聚焦，不自动发送；已有草稿后追加，附件保留。首次发送后切回消息时间线和底部输入框，新建会话恢复欢迎页；专家开场白与推荐问题保持原有配置。演示说明置于页脚。
- 产品名称统一为“西亚斯数字员工”，浏览器标题同步。侧栏整合品牌、新对话、专家市场与聊天记录，不再单列消息菜单或顶部新建会话按钮；底部头像与姓名打开用户菜单，包含个人中心和归档会话快捷入口。能力、连接与系统设置入口隐藏，原页面实现暂存。
- Web 侧栏标准宽 264px，960–1199px 窗口宽 240px，手动折叠为 72px 图标栏；每个页面均可折叠。顶部栏高 64px，显示当前页面或会话标题、聊天对象与演示标识。折叠不重置草稿或历史搜索；空会话标题为“新对话”，历史不高亮。从任意页面点击侧栏“新对话”都进入新的助理空会话并展开侧栏。
- 个人中心增加“基本资料 / 归档会话”两项内部菜单，默认进入基本资料。基本资料页展示用户资料、用量概览和用量记录；归档会话页复用既有搜索、恢复与确认删除流程。用户菜单中的归档会话快捷入口直达同一内部页面。资料展示头像、姓名、学号，仅头像可上传；姓名和学号以只读文字显示，学号 20260001 为明确标注的示例，概览展示 Token 总用量与积分余额；移除预算编辑、预算余额以及通用、模型、权限、记忆、诊断设置。资料仅保留在本次页面会话中，刷新重置。
- 用量记录按使用内容、时间、Token 用量和消耗积分展示，不展示模型名称或按模型划分的明细；按时间倒序，每页 10 条，提供当前范围、总条数及当前页 / 总页数和前后页操作，首末页禁用越界按钮。切页不改变全部记录的Token 总用量与积分余额，重新进入个人中心回到第一页。当前 23 条示例记录分 3 页，共 168,120 Token、消耗 240 积分；积分余额为独立的 1,000 积分示例快照，不通过金额或 Token 换算。上述值均不代表真实账户或计费。
- 专家市场不挂载左侧联系人列表，沿用全局聊天记录，主区沿用原招募页的分类卡片、头像和弹窗组件。Web 学生目录统一来自 `src/student-agent-catalog.ts`，共 6 分类、20 位：学科辅导（高数、线代、大学英语、编程、大学物理、经管）、游戏攻略（王者荣耀、英雄联盟、原神、星穹铁道）、旅游出行（周末周边游、假期旅行、旅行省钱）、恋爱交流（恋爱专家、约会灵感）、情绪陪伴（情感陪伴、压力调节）、校园成长（学习规划、实习求职、社团活动）。支持按名称、专长和分类搜索，无结果时可清空恢复。
- 校园目录统一入口为 `src/campus-agent-catalog.ts`，复用上述 20 位学生资料，并加入 4 类、12 位教职工智能体：教学备课（备课教案、课件大纲、作业设计）、学生指导（辅导员工作、学业指导、毕业论文指导）、科研支持（文献阅读、科研申报、学术写作）、校务办公（通知公文、会议纪要、校园活动统筹）。内置目录合计 10 类、32 位。
- 分类筛选提供“全部 / 学生常用 / 教职工常用 / 我创建的”，下方用途分类随范围变化。范围、用途分类与搜索取交集；切换范围保留搜索词并重置用途分类，打开详情后返回保留筛选。无匹配可一键恢复全部范围、全部分类和空搜索。尚未创建时“我创建的”显示专用空态并保留创建入口。数量概览为全目录数，结果数为当前筛选数；范围仅用于浏览，不代表权限限制。
- 校园目录只提供 Web 演示资料，卡片、详情与新建会话读取同一数据源；不修改正式客户端的企业专家目录或 Runtime 注册。既有历史会话继续保留原智能体身份与可输入状态。
- C 端用户浏览卡片、查看介绍、点击“开始对话”即可使用已有智能体，无需先招募或配置。“创建专家”进入独立页面，沿用当前后台 `ChatAgentWorkspace` 的四个分区：基础与提示词、模型配置、执行能力、输入输出；右侧同步预览专家名片、开场白和推荐问题。
- 基础项包括名称（2–20 字符）、简介（必填，最多 200 字）、系统提示词（必填，最多 8000 字）、开场白（选填，最多 200 字）、推荐问题（最多 4 条，每条 80 字）。模型项包括模型、最大输出 Token（1–32768 整数）、超时（1–120 秒）、流式回复、温度（0–1）、Top P（大于 0 且不超过 1）。
- 能力目录、ID、版本与操作取自相邻 `AI Employee OS-web-admin/src/admin/capabilities.json` 的 2026-09-17 可用普通专家快照，前台只读演示目录位于 `src/expert-capabilities.json`。支持按 Skill / Tool / MCP 分类搜索、勾选能力及具体操作、选择版本；账号与范围固定为使用者本人及其有权资料，写入或发送固定需本人确认。未开放服务账号、共享授权、发布治理与知识库绑定。
- 输入支持文字、文档、表格、图片、音频，输出支持纯文本、Markdown、Word、PDF、JSON、CSV，均至少选择一种。模型示例目录取自后台 `model-center.ts`，图片与音频要求选择支持相应输入的模型。选中能力至少启用一个操作，错误提交切至对应分区并保留输入。
- 返回专家市场或切换页面保留创建草稿，点击“取消”清空，创建成功后重置。自建专家具有独立 ID，加入“我创建的”，支持搜索；详情保留全套配置。新会话显示配置的开场白与推荐问题，点击问题填入输入框，首次发送才进入聊天记录。同名不覆盖已有专家。
- 创建资料、配置和会话均只保存在本次页面会话，刷新重置，不调用 Runtime 或模型。模型参数、权限规则和输入输出格式目前是配置演示，不代表真实推理、附件处理或文件生成已经执行。
- 不展示专家团、状态治理、已有智能体编辑和删除入口。所有目录智能体均可进入明确标记的本地演示会话，不改变正式客户端可调用性。
- 事项边栏、事项卡、事项详情、场景表单、专家团目录与协作流程退出当前前台；助理是默认沟通对象，不承担自动分派或专家团编排。不提供总管配置入口。
- 暂存既有飞书会议组件与独立测试，当前 App 不导入、不挂载、不启动其流程。此调整不改变 Electron / Runtime 实现，不代表真实单智能体执行链已经接通。

## 会话契约

| 对象或操作 | 行为 |
| --- | --- |
| 默认页面 | 打开助理欢迎页，集中展示问候、输入框、四个快捷提问与专家入口；演示边界位于页脚 |
| 新对话 | 直接创建助理的空会话，不继承其他会话的草稿、附件或消息；从专家会话新建也回到助理 |
| 侧栏与顶栏 | 品牌、新对话、专家市场与聊天记录在所有页面可用；点击历史记录直接打开对应会话，新对话作为操作入口不显示页面选中态，底部固定用户菜单。折叠不清空草稿与搜索，标题及副标题随当前页面和聊天对象变化 |
| 消息列表 | 只展示已有消息的会话；默认或新建的空会话不显示卡片，历史记录无选中高亮。输入草稿、选择附件均不入列，首次发送文字或附件后入列并选中；后续消息不重复创建记录 |
| 找专家聊天 | 打开与专家市场相同的卡片目录，保留当前助理会话及其草稿 |
| 专家市场 → 卡片 → 开始对话 | 为所选智能体创建独立会话；详情可返回浏览并保留当前搜索 |
| 身份绑定 | 每个会话固定一个 agentId；标题、输入提示、回复头像与姓名、模型显示对应智能体 |
| 发送 | 空白文本且无附件时禁止发送；Enter 发送，Shift+Enter 换行，中文输入法组合期间不发送 |
| 演示回复 | 本地固定回复，明确标注“演示回复”和未调用模型；不假装完成检索、文件处理或外部操作 |
| 会话切换 | 草稿、附件与消息以会话 ID 隔离；跨智能体或同一智能体的新会话均不共享 |
| 归档对话 | 聊天记录仅提供归档；悬停或键盘聚焦显示归档图标。归档后从历史移除，保留身份、消息、附件与草稿；若归档当前打开的会话则进入新的助理空会话，归档其他会话不切页 |
| 归档管理 | 从用户菜单进入，支持按名称或预览搜索；空列表与搜索无匹配有独立提示。恢复后回到原会话继续聊天，不复制新会话；恢复与删除操作在行悬停或键盘聚焦时显示 |
| 删除对话 | 仅归档页可删除，确认弹窗明确不可撤销；取消不改变数据，确认后移除该会话及消息、附件和草稿，其他会话不受影响。归档、恢复和删除均为 Web 内存演示，刷新重置 |
| 创建专家 | 专家市场入口 → 独立四分区配置页与实时预览 → 校验 → 加入“我创建的”并进入独立空会话；跨页保留草稿、取消清空；详情可核对完整配置 |
| 智能体管理 | 当前 C 端原型支持创建与选用，不提供已有智能体编辑、删除或发布流程 |
| 刷新 | 恢复初始示例，未连接模型与 Runtime，不持久化原型对话 |

## 验收

1. 默认页和新建会话进入助理聊天，专家市场卡片进入所选专家的独立聊天；主流程无事项、场景和专家团入口，导航不显示能力与连接，专家市场无对象列表栏。
2. 智能体身份正确；跨智能体及同一智能体多会话的草稿、附件、消息互不污染。
   空会话不占消息列表记录、不选中其他历史；首次发送（包含纯附件）才入列，重复点击新建不增加空白记录。
3. 校园目录中的智能体无需招募即可进入演示会话，详情不调用真实 Runtime；20 位学生和 12 位教职工智能体身份正确，范围、用途分类与搜索组合、空态恢复和返回浏览正常。
4. 示例附件不能伪装真实文件；用户本地添加的附件保留预览与下载能力。
5. 个人中心从底部用户菜单进入，基本资料菜单内展示资料与用量，可切换归档会话；无模型或预算配置；上传头像同步到侧栏与用户消息，姓名和学号不可修改，离开个人中心不丢失聊天草稿。
6. `web-prototype.test.tsx`、布局/排版契约、Web 类型检查与原型构建通过；浏览器检查默认页、卡片选用、新建会话与无列表栏布局。
7. 创建页覆盖必填、长度、数字范围、推荐问题上限、输入与模型兼容、能力操作及格式至少一项校验；跨页保留草稿、取消清空；创建后配置可核对，推荐问题可填入聊天，同名智能体不串联。
